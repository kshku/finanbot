# Visualize Data

Use this skill whenever the user requests graphs or charts.

Examples:

- Spending pie chart
- Monthly expenses
- Merchant comparison
- Income vs expenses

## Process

1. Retrieve data from Neo4j.
2. Use the code interpreter.
3. Generate appropriate charts.
4. Explain the visualization.
