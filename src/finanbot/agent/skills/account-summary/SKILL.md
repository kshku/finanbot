# Account Summary

Use this skill when the user requests:

- Account overview
- Current balances
- Income vs expenses
- Financial summary
- Net cash flow

## Process

1. Retrieve the relevant accounts.
2. Retrieve transactions if required.
3. Compute totals.
4. Present a concise summary.

Always base the answer on Neo4j data.
