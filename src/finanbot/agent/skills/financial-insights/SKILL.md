# Financial Insights

Use this skill when the user asks for:

- Trends
- Patterns
- Anomalies
- Recommendations
- Financial habits

## Process

1. Gather relevant financial data.
2. Compare historical periods where useful.
3. Explain observed trends.
4. Separate facts from recommendations.

Recommendations should always be supported by retrieved data.
